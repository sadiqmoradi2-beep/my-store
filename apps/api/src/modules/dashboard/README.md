# ماژول Dashboard

`GET /dashboard/summary?branchId=` — فروش/سود امروز و ماه (سود = `(قیمت فروش − بهای تمام‌شده) × تعداد − تخفیف` از snapshot اقلام)، سفارش‌ها به تفکیک وضعیت، تعداد کم‌موجودی، ۵ محصول پرفروش ماه.

مرز «امروز» و «ماه»: منطقه زمانی کابل (UTC+4:30)؛ «ماه» = ماه هجری شمسی جاری.
درآمد = سفارش‌های APPROVED/READY/SHIPPING/DELIVERED.
